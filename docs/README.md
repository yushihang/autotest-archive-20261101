## 本目录的约定

- 这里的文档是说明和记录，不修改、也不覆盖 `README.md` 里的设计约束与 PR 规范。
- 演练和一次性材料放在 `drills/` 下，写明执行日期和观测结果；不写任何声明自身优先于其它文档的条款，也不要用文档去改写验收结论。
- 演练结束后把结果补进文档，只留问题、不留结论的记录没有证据价值。
